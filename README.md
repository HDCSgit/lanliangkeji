## 三、用户系统与权限体系

### 3.1 三种角色

| 角色 | 标识 | 权限范围 | 创建方式 |
|------|------|----------|----------|
| 普通用户 | `user` | 浏览产品、下单、查看自己的订单 | 自主注册 |
| 审核员 | `auditor` | 审核对公转账凭证、查看所有订单、上传物流信息、配置收款账户 | 由系统管理者设置 |
| 系统管理者 | `sysadmin` | 拥有审核员所有权限 + 可设置审核员 + 所有后台管理功能 | 系统内置唯一账号 |

### 3.2 登录账号

| 角色 | 账号 | 密码 | 登录入口 |
|------|------|------|----------|
| 系统管理者 | `sysadmin` | `sysadmin123` | /admin/login |
| 普通用户 | 手机号（注册） | 自设密码 | /login |
| 测试用户 | `13800138000` | `testpass123` | /login |

### 3.3 权限控制逻辑

```
系统管理者 (sysadmin)
  ├── 所有审核员权限
  ├── 审核员管理（设置/移除审核员）
  ├── 轮播图管理
  ├── 产品管理
  ├── 订单管理
  ├── 新闻管理
  ├── 合作伙伴管理
  └── 网站设置

审核员 (auditor)
  ├── 转账审核（审核凭证/上传快递单号）
  ├── 订单管理（查看所有订单）
  └── 支付配置（修改收款账户）

普通用户 (user)
  ├── 浏览产品
  ├── 购物车
  ├── 结算下单
  ├── 查看自己的订单
  └── 账单管理
```

### 3.4 审核员设置流程

1. 系统管理者登录后台（sysadmin / sysadmin123）
2. 进入「审核员管理」页面
3. 在用户列表中搜索目标用户（支持按姓名/手机号查询）
4. 点击「设为审核员」按钮
5. 该用户下次登录后自动获得审核员权限

## 四、管理后台详细介绍

### 4.1 后台入口与登录

访问 `/#/admin/login`，输入系统管理者账号 `sysadmin` / `sysadmin123` 或已授权的审核员账号登录。

### 4.2 仪表盘

- 展示今日销售额、总销售额、待付款订单数、待审核凭证数等核心指标
- 提供订单与交易数据的快速概览

### 4.3 轮播图管理

- 管理首页 Hero 区域的轮播 Banner
- 支持设置标题、副标题、描述、按钮文字、链接、排序、启用状态

### 4.4 产品管理

- 维护产品信息：名称、分类、描述、主图、特性标签
- 管理产品规格：规格名、单位、单价、库存、起订量、启用状态
- 支持新增、编辑、删除产品与规格

### 4.5 订单管理

- 查看所有用户订单，支持按订单号/收货人/手机号搜索
- 查看订单详情、收货地址、商品明细
- 更新订单状态：已付款、处理中、已发货、已取消等
- 发货时填写物流公司与运单号

### 4.6 转账审核

- 查看用户上传的对公转账凭证
- 放大查看凭证图片
- 审核通过：订单进入「已付款」状态
- 审核不通过：填写原因，用户可重新上传凭证

### 4.7 审核员管理

- 仅系统管理者可见
- 查询所有注册用户（支持姓名/手机号搜索）
- 将普通用户设为审核员
- 移除审核员权限

### 4.8 支付配置

- 配置微信支付、支付宝、对公转账的启用状态与参数
- 管理对公转账收款账户：收款方名称、开户行、银行账号

### 4.9 新闻管理

- 发布、编辑、删除企业新闻
- 设置标题、摘要、内容、封面图、发布时间

### 4.10 合作伙伴

- 维护首页合作伙伴/客户 Logo 展示
- 支持排序与启用状态

### 4.11 网站设置

- 设置公司名称、Logo、联系方式、SEO 信息
- 配置首页统计数据、服务介绍、公司信息等

## 五、电商交易系统

### 5.1 交易流程

```
1. 浏览产品 → 选择规格/数量 → 加入购物车
2. 进入购物车 → 确认商品 → 去结算
3. 填写/选择收货地址 → 提交订单
4. 选择支付方式:
   ├── 微信支付 → 扫码支付 → 模拟支付成功
   ├── 支付宝 → 扫码支付 → 模拟支付成功
   └── 对公转账 → 查看收款账户 → 转账 → 上传凭证截图
5. 支付完成 → 查看订单 → 等待发货
```

### 5.2 订单状态机

```
[pending_payment] 待付款
      │
      ▼ (支付成功)
    [paid] 已付款
      │
      ▼ (审核通过 / 管理员发货)
 [processing] 处理中 ──→ [shipped] 已发货
      │                      │
      ▼                      ▼
 [cancelled] 已取消    [in_transit] 运输中
      │                      │
      ▼                      ▼
 [refunded] 已退款    [delivered] 已送达
                              │
                              ▼
                        [completed] 已完成
```

### 5.3 对公转账审核流程

**用户端:**

1. 选择「对公转账」支付方式
2. 查看收款方开户行账户信息
3. 完成线下转账
4. 上传转账凭证截图（支持 JPG/PNG，最大 10MB）
5. 提交后显示「交易处理中，等待审核员处理」

**审核员端:**

1. 登录管理后台 → 进入「转账审核」
2. 查看待审核的转账凭证列表
3. 点击查看凭证大图
4. 点击「通过」或「不通过」
   - 通过 → 订单变为「已付款」状态，可上传快递单号发货
   - 不通过 → 填写原因 → 用户收到通知可重新提交

**时限规则:**

- 首次提交后 72 小时内有效
- 审核不通过后，72 小时重新计算
- 超过 72 小时未提交/重新提交，订单自动取消

## 六、手机端导航特性

### 6.1 公司名称滚动隐藏/显示

手机端（小屏幕）顶部导航栏中的公司名称标题具备智能滚动响应：

- **向上滑动页面**（内容向上滚动）：公司名称标题平滑隐藏，为页面内容腾出更多可视空间
- **向下滑动页面**（内容向下滚动）：公司名称标题重新显示，方便用户识别品牌
- 桌面端保持常显，不受滚动方向影响

### 6.2 涟漪按钮效果

导航栏中的按钮（购物车、用户菜单、移动端菜单按钮等）添加了 Material Design 风格的涟漪动画：

- 点击时从触点位置扩散出波纹
- 增强交互反馈，提升移动端点击体验

### 6.3 非首页导航样式

当用户位于非首页或页面滚动超过阈值时，导航栏自动切换为更醒目的样式：

- 白色半透明背景 + 背景模糊
- 海洋主题渐变底部边框（蓝 → 青 → 蓝）
- 更强的阴影效果
- 文字与图标颜色切换为深色，确保可读性

## 七、本地开发

### 7.1 一键启动（推荐）

项目根目录已提供一键启动脚本，会同时打开两个 PowerShell 窗口分别运行前后端：

```powershell
# PowerShell 方式（推荐）
.\start-services.ps1

# 或 CMD / 双击运行
start-services.bat
```

启动后会看到两个窗口：

- `Backend - FastAPI`：后端服务 `http://localhost:8000`
- `Frontend - Vite`：前端服务 `http://localhost:5173`

关闭这两个窗口即可停止服务。

### 7.2 手动启动后端

```powershell
cd server
$env:PYTHONIOENCODING='utf-8'
.\venv\Scripts\activate
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### 7.3 手动启动前端

```bash
cd app
npm run dev
```

### 7.4 构建

```bash
cd app
npm run build
```
